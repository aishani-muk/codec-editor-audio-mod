What is u(t)?

u ∈ [0, 1] is the stress-proxy intensity. u=0 is intended as passthrough; u=1 is maximum calming edit. In a deployed system u(t) is driven by a physiological signal (EEG/HRV, e.g. via WESAD-trained classifier). For these demo clips, u is a scalar held constant for the whole clip. The editor was trained to honour u, but the cross-clip pattern shown here suggests it learned a single canonical edit and applies it regardless of u.
